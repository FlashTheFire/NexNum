# Workspace Agent Rules

## Git Commit Protocol
- Always commit file changes modularly (file-by-file or in clean logical feature groups) with structured, meaningful commit messages (e.g. `feat(...)`, `fix(...)`, `refactor(...)`).
- Automatically push commits to remote repositories to help maintain and grow the user's GitHub contribution graph (green dots).

## Recommended Strategies to Grow GitHub Green Contribution Dots
- **Atomic Commits (Best Practice)**: Make small, logical commits per feature, fix, or component instead of giant single commits. This keeps Git history clean and grows contribution activity naturally.
- **Feature Branch & Pull Request (PR) Workflow**: Work on feature branches (e.g. `feature/bot-loading`, `fix/poller-refund`) and open PRs to `main`. Merging PRs and reviewing code adds additional contribution events to your graph.
- **Daily Consistent Commits**: Committing daily (even small refactors, documentation updates, or test cases) creates a consistent green streak on your profile.
- **Issue Tracking & Milestone Linking**: Create GitHub Issues for planned features or bugs, and link your commits using `#issue_number` (e.g., `fix(polling): resolve loop #12`).

## Profile & Contribution Boost Strategies
- **Modular, Incremental Commits**: Split work into smaller, focused commits (e.g., UI layout, API handler, refactor, bug fix) instead of single giant dumps. Each commit event adds to your daily activity score.
- **Branch & Pull Request (PR) Workflow**: Create feature branches (`git checkout -b feature/name`), push the branch, and open a PR on GitHub. Merging PRs and performing code reviews triggers Pull Request & Review contribution activity on your graph.
- **Maintain Daily Streaks**: Make it a habit to push code daily—even small updates like refactoring a helper function, updating documentation (`README.md`), adding JSDoc comments, or adding test cases.
- **Open Source & Issue Contributions**: Report issues, submit bug fixes, or add features to public open-source repositories in topics you use (e.g., Next.js, Prisma, Tailwind, Telegram Bot SDKs). Contributions to public repos increase public profile visibility, star counts, and green dot density.
- **Profile Readme Customization**: Create a GitHub profile repository named `FlashTheFire/FlashTheFire` with a custom `README.md`. Add dynamic stats cards (e.g., `github-readme-stats`, streak stats, top languages) and project showcase links.
