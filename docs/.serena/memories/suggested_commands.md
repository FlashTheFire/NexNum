# Commands (Windows)
- Install: `npm ci`
- Typecheck: `npm run typecheck`
- Lint: `npm run lint`
- Tests: `npm run test`; targeted Vitest: `npx vitest run path/to/test`
- Build/start: `npm run build`, `npm run start`
- Local infra: `npm run infra:up`; stop with `npm run infra:down`.
- Dev: `npm run dev`; combined app/socket: `npm run dev:full`.
- Use PowerShell commands rather than Unix `grep`/`sed`; `rg` is available for search.
