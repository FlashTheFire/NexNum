# Stack
- Node.js >=20; npm lockfile (`package-lock.json`).
- Next.js ^16.1.7, React 19, TypeScript 5.9, Prisma 7.3 with PostgreSQL adapter/client.
- Vitest 4, Playwright 1.57, ESLint 8 with Next config, Tailwind 3.4.
- BullMQ/Redis, Socket.IO, SWR, Zustand, Zod 4, Sentry, Meilisearch.
- Path alias `@/*` maps to `src/*` via tsconfig; environment/config files are root-level.
